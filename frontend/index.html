Sentiment Analysis

Analyse news sentiment using a cloud AI provider or a local model. Fetches headlines from Yahoo Finance & Google News.

AI Provider

Your key is only sent to the selected provider and is never stored on any server
Override the default model (e.g. gpt-4o, claude-opus-4-20250514, gemini-1.5-pro)
Directory containing the base model weights (config.json, *.safetensors, etc.)
Directory containing the fine-tuned LoRA adapter (adapter_config.json, adapter_model.*)
Requirements

Local model requires torch, transformers, and optionally peft (for LoRA) + bitsandbytes (for 4-bit quantisation). A CUDA GPU with 8+ GB VRAM is recommended. CPU fallback is available but slow.

Parameters

More articles = more accurate but costs more API tokens
Only analyse news from the last N days (default 15)
How it works

Headlines are fetched from Yahoo Finance and Google News, then sent to the AI model for positive/negative/neutral classification. Processed in batches of 30.

Cost estimate

~50 headlines per stock costs roughly $0.01-0.03 per asset depending on the provider. A 15-stock portfolio: ~$0.15-0.45 total.

Already-classified headlines are cached for 7 days to save API costs. Clear the cache to re-analyze all news from scratch.
